isync: free IMAP and MailDir mailbox synchronizer

**isync** is a command line application which synchronizes mailboxes;
currently [Maildir](http://cr.yp.to/proto/maildir.html) and [IMAP4](https://tools.ietf.org/html/rfc3501) mailboxes are
supported.
New messages, message deletions and flag changes can be propagated both ways. **isync** is suitable for use in IMAP-disconnected mode.

Synchronization is based on unique message identifiers (UIDs), so no
identification conflicts can occur (as opposed to some other mail
synchronizers).
Synchronization state is kept in one local text file per mailbox pair;
multiple replicas of a mailbox can be maintained.

**isync** is free software in the sense of the [GNU GPL v2](http://www.gnu.org/licenses/gpl2.html).

Features

Fine-grained selection of synchronization operations to perform
Synchronizes single mailboxes or entire mailbox collections
Partial mirrors possible: keep only the latest messages locally
Trash functionality: backup messages before removing them
IMAP features:
  * TLS/SSL via IMAPS and STARTTLS for encryption
  * SASL for authentication
  * Pipelining for maximum speed

Other mailbox synchronizers
  * [mailsync](http://mailsync.sourceforge.net/) is also written in C, but uses UW c-client instead of homegrown drivers,
so it supports more mailbox formats directly, but is also much slower
(no parallelized operation)
  * [offlineIMAP](https://www.offlineimap.org/) is written in Python
