**LaTeX** ([/ˈlɑːtɛx/](/wiki/Help:IPA/English "Help:IPA/English") [*LAH-tekh*](/wiki/Help:Pronunciation_respelling_key "Help:Pronunciation respelling key") or [/ˈleɪtɛx/](/wiki/Help:IPA/English "Help:IPA/English") [*LAY-tekh*](/wiki/Help:Pronunciation_respelling_key "Help:Pronunciation respelling key"), to rhyme with "blech"[[2]](#cite_note-2)), often stylized as  **LaTeX**, is a [software system](/wiki/Software_system "Software system") for [typesetting](/wiki/Typesetting "Typesetting") documents,[[3]](#cite_note-Lamport1986-3) based on the [TeX](/wiki/TeX "TeX") typesetting system. LaTeX provides a high-level, descriptive markup language to use TeX more easily: TeX handles the document layout, while LaTeX handles the content side for document processing. Because the plain TeX formatting commands are elementary, it provides authors with ready-made commands for formatting and layout requirements such as chapter headings, footnotes, cross-references and bibliographies.

LaTeX was originally written in the early 1980s by [Leslie Lamport](/wiki/Leslie_Lamport "Leslie Lamport") at [SRI International](/wiki/SRI_International "SRI International").[[4]](#cite_note-4) The current version is LaTeX2e, first released in 1994 and incrementally updated since 2015. This update policy replaced earlier plans for a separate release of LaTeX3, which had been in development since 1989.[[5]](#cite_note-Latex3planning-5) LaTeX is [free software](/wiki/Free_software "Free software") and is distributed under the [LaTeX Project Public License (LPPL)](/wiki/LaTeX_Project_Public_License "LaTeX Project Public License").[[6]](#cite_note-6)

Like TeX, LaTeX started as a writing tool for mathematicians and computer scientists, but from early in its development, it has also been taken up by scholars who needed to write documents that include complex math expressions or non-Latin scripts,[[7]](#cite_note-7)[[8]](#cite_note-8) such as [Arabic](/wiki/Arabic_script "Arabic script"), [Devanagari](/wiki/Devanagari "Devanagari"), and Chinese.[[9]](#cite_note-9)

History

In the early 1980s, Leslie Lamport was working at SRI, where he needed to write TeX macros for his own use. He thought that with a little extra effort, he could make a general package usable by others. Having done so, he released versions of his LaTeX macros in 1984 and 1985. Peter Gordon, an editor at [Addison-Wesley](/wiki/Addison-Wesley "Addison-Wesley"), convinced Lamport to write a LaTeX user's manual for publication. Lamport was initially skeptical that anyone would pay money for it,[[10]](#cite_note-Lamport2018-10) but it came out in 1986[[3]](#cite_note-Lamport1986-3) and sold hundreds of thousands of copies.[[10]](#cite_note-Lamport2018-10) On 21 August 1989, at a TeX Users Group (TUG) meeting at Stanford, Lamport agreed to turn over maintenance and development of LaTeX to Frank Mittelbach. Mittelbach, along with Chris Rowley and Rainer Schöpf, formed the LaTeX3 team; in 1994, they released LaTeX2e, the current standard version. LaTeX3 has been discontinued as a separate format; since 2018, it has been a programming layer within LaTeX2e.[[5]](#cite_note-Latex3planning-5)

Typesetting system

LaTeX attempts to follow the design philosophy of [separating presentation from content](/wiki/Separation_of_content_and_presentation "Separation of content and presentation"), so that authors can focus on the content of what they are writing without attending simultaneously to its visual appearance. In preparing a LaTeX document, the author specifies the logical structure using commands such as *chapter*, *section*, *table*, *figure*, etc., and lets the LaTeX system handle the formatting and layout of these structures. As a result, it encourages the separation of the layout from the content – while still allowing manual typesetting adjustments whenever needed. This concept is similar to the mechanism by which many [word processors](/wiki/Word_processor "Word processor") allow styles to be defined globally for an entire document, or the use of [Cascading Style Sheets](/wiki/Cascading_Style_Sheets "Cascading Style Sheets") in styling HyperText Markup Language ([HTML](/wiki/HTML "HTML")) documents.

The LaTeX system is a [markup language](/wiki/Markup_language "Markup language") that handles typesetting and rendering,[[11]](#cite_note-11) and can be arbitrarily extended by using the underlying [macro language](/wiki/Macro_language "Macro language") to develop custom macros such as new environments and commands. Such macros are often collected into *packages,* which could then be made available to address some specific typesetting needs such as the formatting of complex mathematical expressions or graphics (e.g., the use of the `align` environment provided by the `amsmath` package to produce aligned equations).

To create a document in LaTeX, a user first creates a file, such as `document.tex`, typically using a [text editor](/wiki/Text_editor "Text editor").[[12]](#cite_note-12) The user then gives their `document.tex` file as input to the TeX program (with the LaTeX macros loaded), which prompts TeX to write out a file suitable for onscreen viewing or printing.[[13]](#cite_note-13) This write-format-preview cycle is one of the chief ways in which working with LaTeX differs from the [What-You-See-Is-What-You-Get](/wiki/WYSIWYG "WYSIWYG") (WYSIWYG) style of document editing. It is similar to the code-compile-execute cycle known to computer programmers. Today, many LaTeX-aware editing programs make this cycle a simple matter through the pressing of a single key while showing the output preview on the screen beside the input window. Some online LaTeX editors even automatically refresh the preview,[[14]](#cite_note-14)[[15]](#cite_note-15)[[16]](#cite_note-16)[[17]](#cite_note-17)[[18]](#cite_note-18) while other online tools provide incremental editing in-place, mixed in with the preview in a single window.[[19]](#cite_note-19)

Pronunciation and typography

![](//upload.wikimedia.org/wikipedia/commons/thumb/9/92/LaTeX_logo.svg/120px-LaTeX_logo.svg.png)

The characters 'T', 'E', and 'X' in the name come from the [Greek](/wiki/Greek_alphabet "Greek alphabet") [capital letters](/wiki/Capital_letter "Capital letter") [tau](/wiki/Tau "Tau"), [epsilon](/wiki/Epsilon "Epsilon"), and [chi](/wiki/Chi_(letter) "Chi (letter)"), as the name of [TeX](/wiki/TeX "TeX") derives from the [Ancient Greek](/wiki/Ancient_Greek_language "Ancient Greek language"): τέχνη ('skill', 'art', 'technique'); for this reason, TeX's creator [Donald Knuth](/wiki/Donald_Knuth "Donald Knuth") promotes its pronunciation as [/tɛx/](/wiki/Help:IPA/English "Help:IPA/English") ([*tekh*](/wiki/Help:Pronunciation_respelling_key "Help:Pronunciation respelling key"))[[20]](#cite_note-20) (that is, with a [voiceless velar fricative](/wiki/Voiceless_velar_fricative "Voiceless velar fricative") as in Modern Greek, or the 'ch' in '[loch](/wiki/Loch "Loch")'). Lamport remarks that "TeX is usually pronounced *tech*, making *lah*-tech, lah-*tech*, and *lay*-tech the logical choices; but language is not always logical, so *lay-tecks* is also possible."[[21]](#cite_note-21)

The name is printed in running text with a typographical [logo](/wiki/Logo "Logo"): LaTeX. In media where the logo cannot be precisely reproduced in running text, the word is typically given the unique capitalization LaTeX. Alternatively, the TeX, LaTeX,[[22]](#cite_note-22) and [XeTeX](/wiki/XeTeX "XeTeX")[[23]](#cite_note-23) logos can also be rendered via pure [CSS](/wiki/CSS "CSS") and [XHTML](/wiki/XHTML "XHTML") for use in graphical [web browsers](/wiki/Web_browser "Web browser") – by following the specifications of the internal `\LaTeX` macro.[[24]](#cite_note-24)

Related software

![](//upload.wikimedia.org/wikipedia/commons/thumb/b/bf/CoCalc_tikz_diagrams.webp/250px-CoCalc_tikz_diagrams.webp.png)

As a macro package, LaTeX provides a set of macros for TeX to interpret. There are many other macro packages for TeX, including Plain TeX, [GNU Texinfo](/wiki/GNU_Texinfo "GNU Texinfo"), [AMSTeX](/wiki/AMSTeX "AMSTeX"), [Chemfig](/wiki/Chemfig "Chemfig"), chemmacros,[[25]](#cite_note-25) [PSTricks](/wiki/PSTricks "PSTricks"), [PSfrag](/wiki/PSfrag "PSfrag"), and [ConTeXt](/wiki/ConTeXt "ConTeXt").

When TeX "compiles" a document, it follows (from the user's point of view) the following processing sequence: Macros → TeX → Driver → Output. Different implementations of each of these steps are typically available in TeX distributions. Traditional TeX will output a [DVI](/wiki/DVI_(file_format) "DVI (file format)") file, which is usually converted to a [PostScript](/wiki/PostScript "PostScript") file. In 2000, Hàn Thế Thành and others wrote an implementation of TeX called [pdfTeX](/wiki/PdfTeX "PdfTeX"), which also outputs to [PDF](/wiki/PDF "PDF") and takes advantage of features available in that format.[[26]](#cite_note-26) The [XeTeX](/wiki/XeTeX "XeTeX") engine developed by Jonathan Kew, on the other hand, merges modern font technologies and Unicode with TeX.[[27]](#cite_note-27) [LuaTeX](/wiki/LuaTeX "LuaTeX") is an extended version of pdfTeX using Lua as an embedded scripting language.[[28]](#cite_note-luatex-28)

Compatibility and converters

LaTeX documents (`*.tex`) can be opened with any text editor. They consist of plain text and contain no hidden formatting codes or [binary](/wiki/Binary_file "Binary file") information. TeX documents can also be shared by rendering the LaTeX file to other formats such as [OpenDocument](/wiki/OpenDocument "OpenDocument"), [XML](/wiki/XML "XML"), or class (`*.cls`) files. LaTeX can also (and commonly is) rendered to PDF files using the LaTeX extension pdfLaTeX. LaTeX files containing [Unicode](/wiki/Unicode "Unicode") text can be processed into PDFs with the `inputenc` package, or by the TeX extensions XeLaTeX and LuaLaTeX.

[TeX4ht](/wiki/TeX4ht "TeX4ht") is a converter that can translate TeX and LaTeX documents to HTML and certain XML formats. It is now included preconfigured with all TeX distributions.
HeVeA is a converter written in [OCaml](/wiki/OCaml "OCaml") that converts LaTeX documents to [HTML5](/wiki/HTML5 "HTML5"). This way, documents such as scientific papers, primarily typeset for printing, can be placed on the [World Wide Web](/wiki/World_Wide_Web "World Wide Web") for online viewing. It is licensed under the [Q Public License](/wiki/Q_Public_License "Q Public License").[[29]](#cite_note-29)
LaTeX2HTML is a converter written in [Perl](/wiki/Perl "Perl") that converts LaTeX documents to HTML. It is licensed under [GPL](/wiki/GNU_General_Public_License "GNU General Public License") v2.[[30]](#cite_note-30) The latest updates are available from Comprehensive TeX Archive Network ([CTAN](/wiki/CTAN "CTAN")).[[31]](#cite_note-31)
LaTeX2RTF is a converter written in [C](/wiki/C_(programming_language) "C (programming language)") that converts LaTeX documents to [RTF](/wiki/Rich_Text_Format "Rich Text Format"). It is licensed under GPL v2 or later.[[32]](#cite_note-32)
[LaTeXML](/wiki/LaTeXML "LaTeXML") is a converter written in Perl that converts LaTeX documents into a variety of XML-based formats, including HTML5 (with [MathML](/wiki/MathML "MathML")), [ePub](/wiki/EPub "EPub") ebooks, [JATS](/wiki/Journal_Article_Tag_Suite "Journal Article Tag Suite"), and [TEI](/wiki/Text_Encoding_Initiative "Text Encoding Initiative"). It was developed at the [National Institute of Standards and Technology](/wiki/National_Institute_of_Standards_and_Technology "National Institute of Standards and Technology") by [US Federal Government employees and is therefore in the public domain](/wiki/Copyright_status_of_works_by_the_federal_government_of_the_United_States "Copyright status of works by the federal government of the United States"). It is available for free.[[33]](#cite_note-33)
[Pandoc](/wiki/Pandoc "Pandoc") is a "universal document converter" able to transform LaTeX (as well as other formats) into many different file formats, including HTML5, ePub, OpenDocument (`*.odt`), Microsoft [Office Open XML](/wiki/Office_Open_XML "Office Open XML") (`*.docx`), and even text with [MediaWiki markup](/wiki/MediaWiki#Markup "MediaWiki") as used in [Wikipedia](/wiki/Wikipedia "Wikipedia"). It is licensed under GPL v2.[[34]](#cite_note-34)
LaTeX has become the [de facto standard](/wiki/De_facto_standard "De facto standard") to typeset mathematical expression in scientific documents.[[35]](#cite_note-Gaudeul2006-35)[[36]](#cite_note-36) Hence, there are several conversion tools focusing on mathematical LaTeX expressions, such as converters to MathML or [Computer Algebra System](/wiki/Computer_Algebra_System "Computer Algebra System").

[MathJax](/wiki/MathJax "MathJax") is a [JavaScript](/wiki/JavaScript "JavaScript") library for converting LaTeX to MathML, picture formats including [SVG](/wiki/Scalable_Vector_Graphics "Scalable Vector Graphics") and [PNG](/wiki/Portable_Network_Graphics "Portable Network Graphics"), or HTML for embedding within a webpage.
[KaTeX](/wiki/KaTeX "KaTeX") is a JavaScript library for converting LaTeX to HTML and MathML. It is developed by [Khan Academy](/wiki/Khan_Academy "Khan Academy"), and is among the fastest LaTeX to HTML converters.[[38]](#cite_note-38)
The [Wikimedia Foundation](/wiki/Wikimedia_Foundation "Wikimedia Foundation") uses MathJax to build Mathoid, a [web service](/wiki/Web_service "Web service") that uses [Node.js](/wiki/Node.js "Node.js") to render math that is used in Wikipedia.[[37]](#cite_note-37)
Licensing

LaTeX is typically distributed along with plain [TeX](/wiki/TeX "TeX") under a [free software licence](/wiki/Free_software_license "Free software license"): the [LaTeX Project Public License](/wiki/LaTeX_Project_Public_License "LaTeX Project Public License") (LPPL).[[39]](#cite_note-39) The LPPL is not [compatible](/wiki/License_compatibility "License compatibility") with the [GNU General Public License](/wiki/GNU_General_Public_License "GNU General Public License"), as it requires that modified files must be clearly differentiable from their originals (usually by changing the filename); this was done to ensure that files that depend on other files will produce the expected behavior and avoid [dependency hell](/wiki/Dependency_hell "Dependency hell"). The LPPL is [Debian Free Software Guidelines](/wiki/Debian_Free_Software_Guidelines "Debian Free Software Guidelines") (DFSG) compliant as of version 1.3. As [free software](/wiki/Free_software "Free software"), LaTeX is available on most operating systems.

LaTeX2e is the current version of LaTeX, since it replaced LaTeX 2.09 in 1994.[[40]](#cite_note-:1-40) As of 2020[[update]](https://en.wikipedia.org/w/index.php?title=LaTeX&action=edit), LaTeX3, which started in the early 1990s, is under a long-term development project.[[5]](#cite_note-Latex3planning-5) Planned features include improved syntax (separation of content from styling), [hyperlink](/wiki/Hyperlink "Hyperlink") support, a new user interface, access to arbitrary fonts and a new documentation.[[41]](#cite_note-41) Some LaTeX3 features are available in LaTeX2e using packages,[[42]](#cite_note-42) and by 2020 many features have been enabled in LaTeX2e by default for a gradual transition.[[5]](#cite_note-Latex3planning-5)

There are many commercial implementations of the entire TeX system. System vendors may add extra features like added [typefaces](/wiki/Typeface "Typeface") and [telephone support](/wiki/Help_desk "Help desk"). [LyX](/wiki/LyX "LyX") is a [free software](/wiki/Free_software "Free software"), [WYSIWYM](/wiki/WYSIWYM "WYSIWYM") visual document processor that uses LaTeX for a back-end.[[43]](#cite_note-43) [TeXmacs](/wiki/TeXmacs "TeXmacs") is a free, [WYSIWYG](/wiki/WYSIWYG "WYSIWYG") editor with similar functionalities as LaTeX, but with a different typesetting engine.[[44]](#cite_note-44) Other WYSIWYG editors that produce LaTeX include [Scientific Word](/wiki/Scientific_Word "Scientific Word") on Windows and [macOS](/wiki/MacOS "MacOS").

Many community-supported TeX distributions are available.

Adoption

LaTeX is widely used in academia for the communication and publication of scientific documents and technical note-taking in many fields, owing partially to its support for complex mathematical notation.[[45]](#cite_note-45)[[35]](#cite_note-Gaudeul2006-35) It also has a prominent role in the preparation and publication of books and articles that contain complex [multilingual materials](/wiki/Multilingualism "Multilingualism"), such as Arabic and Greek.[[46]](#cite_note-46) LaTeX uses the TeX typesetting program for formatting its output, and is itself written in the TeX [macro](/wiki/Macro_(computer_science) "Macro (computer science)") language.

LaTeX can be used as a standalone document preparation system or as an intermediate format. In the latter role, for example, it is sometimes used as part of a pipeline for translating [DocBook](/wiki/DocBook "DocBook") and other [XML](/wiki/XML "XML")-based formats for PDF. The typesetting system offers programmable [desktop publishing](/wiki/Desktop_publishing "Desktop publishing") features and extensive facilities for automating most aspects of typesetting and desktop publishing, including numbering and cross-referencing of tables and figures, chapter and section headings, graphics, page layout, indexing and [bibliographies](/wiki/Bibliography "Bibliography").
